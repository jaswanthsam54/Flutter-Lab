# Contributing to Flutter Lab & Calculator Project

Thank you for contributing to the **Flutter & Dart Laboratory** project!

## 🛠️ Development Guidelines
1. Ensure all code follows official Dart style conventions (`flutter format`).
2. Write unit tests in `test/` for any new logic or service added.
3. Use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `refactor:`).
