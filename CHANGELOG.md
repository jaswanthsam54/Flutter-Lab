# Changelog

All notable changes to the **Flutter Lab Calculator App** are documented here.

## [1.1.0] - 2026-11-13
### Added
- Complete 10-experiment Flutter laboratory syllabus coverage.
- Standalone `ScientificScreen` and `HistoryScreen`.
- `CurrencyScreen` integration with simulated REST exchange rate logic.
- `CustomCalculationScreen` featuring form validation.
- Centralized `AppRoutes` and `AppDrawer`.

## [1.0.0] - 2026-10-30
### Added
- Standard Calculator with basic arithmetic.
- Scientific keypad and history drawer.
